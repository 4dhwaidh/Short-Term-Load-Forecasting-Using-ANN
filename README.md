# Short-Term Load Forecasting Using ANN

A machine learning project that forecasts short-term electricity demand using historical load data and time-based and weather-related features. The project uses an Artificial Neural Network (ANN) to learn patterns in demand and estimate future electricity consumption.

- **Input Data:** Uses historical demand, moving averages, day of the week, hour of the day, and weather-related features available in the dataset.
- **Feature Engineering:** Prepares time-based and demand-related inputs for forecasting.
- **Model:** Implements an Artificial Neural Network for short-term load prediction.
- **Data Split:** Uses separate training and testing data to evaluate the model.
- **Evaluation:** Assesses forecast performance using the evaluation measures implemented in the project.

## Technologies Used

MATLAB · Artificial Neural Networks · Time-Series Data · Feature Engineering

## Project Workflow

1. Load the electricity-demand dataset.
2. Prepare the data and select the input features.
3. Split the data into training and testing sets.
4. Train the ANN model.
5. Generate predictions and evaluate the results.

## How to Run

1. Clone or download the repository.
2. Open the MATLAB script in MATLAB.
3. Place the required dataset in the expected location.
4. Update the dataset path if necessary and run the script.

## Project Status

The project implements an ANN-based short-term electricity load forecasting workflow, from data preparation and feature engineering to model training and evaluation.
